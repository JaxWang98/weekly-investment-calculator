# Investment Calculator

一个用于测算定投收益的静态网页工具，适合直接部署到 GitHub Pages。

## 功能

- 支持每周定投和每月定投
- 支持设置期初已有资产，不必从 0 开始计算
- 支持阶段性接力计算，例如从第 2 年开始继续测算后续定投收益
- 输入定投金额、一次性投入预期年化收益率、后续定投年限
- 计算总投入、最终总资产、累计收益、累计收益率
- 展示“定投后实际年化”，用于反映分批入场后相对一次性投入预期年化被摊薄后的实际表现
- 提供年度收益表格和趋势图，便于观察长期复利效果

## 文件结构

- `index.html`: 页面结构和文案
- `style.css`: 页面样式
- `script.js`: 输入校验、收益计算、表格与图表渲染逻辑

## 使用方式

这是一个纯前端项目，不依赖构建工具。

1. 直接双击打开 `index.html`
2. 或者使用任意静态服务器在本地预览

例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`

## 计算口径

- 输入的“预期年化收益率”表示一次性投入场景下的目标年化收益率
- 程序会先将预期年化换算为等价周收益率或月收益率，再按所选定投频率复利计算
- 期初已有资产会作为阶段开始时的存量资金继续参与后续复利
- 历史累计投入会纳入总投入和累计收益，但不会重复计入后续当年投入
- “定投后实际年化”按总投入资金与最终资产折算成年化收益率，用于体现资金分批入场后的摊薄效果

这意味着：

- 同样的预期年化下，定投后实际年化通常会低于一次性投入预期年化
- 定投周期越长、资金越晚进入市场，摊薄效应通常越明显
- 如果已经完成了一段定投，可以填写“已完成定投年限”和“历史累计投入”，从下一阶段继续计算

## 部署到 GitHub Pages

1. 在 GitHub 创建一个新仓库
2. 本地关联远程仓库：

```bash
git remote add origin <your-repo-url>
git branch -M main
git add .
git commit -m "Initial commit"
git push -u origin main
```

3. 在 GitHub 仓库设置中开启 Pages，选择从 `main` 分支部署
